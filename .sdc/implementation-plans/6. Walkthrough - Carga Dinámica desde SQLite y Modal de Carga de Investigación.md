# Walkthrough: Carga Dinámica desde SQLite y Modal de Carga de Investigación

Se eliminaron los datos mock/hardcodeados del frontend, conectando la interfaz al 100% con la base de datos SQLite `aml_copilot.db`, y se incorporó un modal central de progreso para simular y visualizar las etapas de investigación del Copilot.

---

## 🛠️ Cambios Implementados

### 1. Backend API (`backend/api/alerts.py`)
- Se implementó el endpoint `GET /api/v1/alerts/{alert_id}/context`:
  - Obtiene los detalles de la alerta (`get_alert_service`).
  - Obtiene el perfil KYC del cliente real desde SQLite (`get_customer_profile_service`).
  - Calcula determinísticamente el resumen transaccional de los últimos 30 días desde la tabla `transactions` de SQLite (`get_transaction_summary_service`).

### 2. Frontend UI (`frontend/index.html` & `frontend/index.css`)
- **Limpieza de Mocks:** Se reemplazaron los valores estáticos de Martín Pereira por estados iniciales dinámicos.
- **Efecto Shimmer / Loading:** Se añadieron estilos de carga fluida para las tarjetas de KYC y Resumen Transaccional mientras se consulta la API.
- **Overlay Central de Investigación (`#investigationProgressModal`):**
  - Spinner y escáner animado con estética glassmorphism y tema oscuro.
  - Barra de progreso con porcentaje reactivo.
  - Etapas visuales secuenciales:
    1. *Consultando perfil KYC y registros del cliente en SQLite...*
    2. *Calculando métricas transaccionales y análisis de volumen...*
    3. *Contrastando hallazgos con las Políticas Institucionales AML...*
    4. *Estructurando reporte explicable y recomendación de cumplimiento...*

### 3. Lógica del Frontend (`frontend/app.js`)
- `selectAlert()` invoca `fetchAlertContext()` para cargar inmediatamente desde SQLite:
  - Ocupación, Ingreso mensual declarado, Origen de fondos, Estado KYC, Notas de cumplimiento.
  - % Cambio de volumen a 30 días, Inflow reciente, Outflow reciente, Ratio vs Ingreso, Lista de contrapartes nuevas detectadas.
- `triggerInvestigation()` despliega el modal central, simula la transición de pasos durante la recolección de evidencia y, al recibir la respuesta, cierra el modal y presenta el informe estructurado con las opciones de Aprobación/Rechazo habilitadas.

## 🚀 Instrucciones para Probar en el Navegador

1. **Iniciar el Servidor Backend:**
   ```bash
   python -m uvicorn backend.main:app --port 8000 --reload
   ```
2. **Abrir la Consola Web:**
   Navega a [http://127.0.0.1:8000](http://127.0.0.1:8000).
3. **Verificar la Carga Dinámica:**
   - Haz clic en diferentes alertas en la lista lateral:
     - **AML-001 (Martín Pereira / CUST-004):** Consultant, $4,500.00/mes, +342.0% volumen.
     - **AML-003 (Sofía González / CUST-005):** Import Business Owner, $8,000.00/mes, ratios y contrapartes de su propio historial.
     - **AML-007 (Camila Varela / CUST-011):** Graphic Designer, $2,800.00/mes, KYC Status `INCOMPLETE`.
4. **Verificar el Loading de Investigación:**
   - Selecciona cualquier alerta y presiona **"⚡ Investigar con Copilot"**.
   - Observa la animación central con las 4 etapas de análisis antes de que se despliegue el informe final.
