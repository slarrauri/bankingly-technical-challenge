# Una decisión importante sobre el modelo

No quiero que `risk` de la contraparte determine directamente el resultado.

Por ejemplo:

```text
CP-014
Risk: MEDIUM
```

no debería significar:

```text
ESCALATE_ALERT
```

El agente tiene que integrar:

```text
Customer profile
+
Counterparty
+
Transaction behavior
+
Historical behavior
+
AML policies
+
Missing information
```

para llegar a una recomendación.

Esto es exactamente lo que queremos demostrar con el PoC.
